=== 4. EXAM SCENARIO CLASS DIAGRAM ===

The current state diagram defines this normal workflow:
   WrittenPaper  --deliverPaper()--> DeliveredPaper
   DeliveredPaper --mark()----------> StartMarking
   StartMarking  --pauseMarking()---> PauseMarking
   PauseMarking  --mark()-----------> StartMarking
   StartMarking  --finMarking()-----> MarkedPaper
   MarkedPaper   --captureMark()----> CapturedPaper
   CapturedPaper --archivePaper()--> ArchivedPaper

The class diagram's operation names are retained; the state operations implement
the corresponding transitions:
   WrittenState.nextState()       -> DeliveredState
   DeliveredState.nextState()     -> MarkingState
   MarkingState.pause()           -> PausedState
   PausedState.resumeMarking()    -> MarkingState
   MarkingState.completeMarking() -> MarkedState
   MarkedState.nextState()        -> CapturedState
   CapturedState.nextState()      -> archived terminal (null state pointer)

The ArchivedPaper terminal has no corresponding state class in the class diagram;
the implementation uses a null state pointer to represent it. Other state methods
not covered by the normal lifecycle remain stubs. State objects retain a
non-owning pointer to their paper so their UML no-argument methods can perform
transitions.

Observer notifications originate at AbstractExamPaper. Attach the chain head as
an observer; its update starts the chain, which forwards using Marker::next.
ModuleCoordinator was scrapped and is intentionally not implemented.

The component API is getBonusMarks() : double and getExtraTime() : int.
ExamPaperGroup aggregates those values; decorators add to them.

The facade owns papers it creates; returned ExamPaper pointers are borrowed.
The facade selects a Strategy for each paper metric: highest question percentage,
lowest question percentage, or marks per allocated exam minute. Question-level
scores are retained by the paper; unanswered questions receive zero. Cohort
statistics are grouped by year, with fixed outcome bands (<50 failure,
50-<75 pass, >=75 distinction). The statistics memento snapshots the cohort
rates and each resolved paper's metric results. Papers with incomplete marking
or unresolved escalation are excluded.
